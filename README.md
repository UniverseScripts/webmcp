# Executable ArchitectureLab

A WebMCP-native architecture studio where a person and an AI agent co-design a semantic
system model, simulate request flows under load and failure, and review every change before
it is applied.

> Built for the [OpenAI WebMCP Challenge](https://webmcp.devpost.com/). Work in progress —
> setup instructions, live URL, and the exact test prompt land here before submission.
